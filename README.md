# Nerone Basket Anzio

Repository del sito ufficiale del Nerone Basket Anzio, società amatoriale di pallacanestro di Anzio.

Il sito raccoglie risultati, classifiche, calendario, roster, profili dei giocatori, notizie e contenuti multimediali del club. Lo storico delle stagioni resta nel repository e viene pubblicato come sito statico su GitHub Pages.

Il progetto è una versione specializzata di [WebMAKER](https://github.com/PlayMAKER-apps/webmaker), parte del [PlayMAKER Ecosystem](https://playmaker-apps.github.io/).
