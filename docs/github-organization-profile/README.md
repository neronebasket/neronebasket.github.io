# Nerone Basket Anzio

Il Nerone Basket Anzio è una società amatoriale di pallacanestro nata ad Anzio. Il progetto unisce attività sportiva, partecipazione e aggregazione, creando occasioni per avvicinarsi o tornare a giocare a basket sul territorio.

Su GitHub sviluppiamo e manteniamo il sito ufficiale del club, il suo archivio storico e gli strumenti utilizzati per pubblicare risultati, calendari, roster, notizie e contenuti multimediali.
